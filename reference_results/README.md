# Frozen reference results

These CSV files are the final reproduction and sensitivity-audit outputs supplied with the manuscript analysis code.

They are included so that users can compare regenerated results with the frozen manuscript state.

Important:

- `CR2_small_cluster_results.csv` contains the final CR2-HTZ numerical results.
- The recovered fixed CR2-HTZ implementation is provided in `scripts/12_CR2_small_cluster_sensitivity.R`.
- `reproduction_provenance_notes.csv` reflects the audit state at the time it was created; the Figure 4 trimming-rule provenance was subsequently recovered and is documented in `docs/PROVENANCE_NOTES.md`.
- `figure5_maintext_pathway_enrichment.csv` preserves the frozen pathway-enrichment state used for manuscript reporting.
- `cell4_frozen_maintext_pathway_audit.csv` records the corresponding frozen reproduction-audit state.
